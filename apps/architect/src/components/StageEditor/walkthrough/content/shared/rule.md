## Build a rule

<!-- dialog: construct a rule -->

A rule defines a logical constraint that the interview network (nodes, edges and ego data) must satisfy in order to remain part of the network that is used by this stage.

When a filter has more than one rule, you choose whether all of them must match or whether any one is enough.

Read more about [network filtering](https://documentation.networkcanvas.com/design-protocols/key-concepts/network-filtering) and [skip logic](https://documentation.networkcanvas.com/design-protocols/key-concepts/skip-logic).
