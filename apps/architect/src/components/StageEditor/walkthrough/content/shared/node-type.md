## Name the type

<!-- dialog: create new node type | edit this node type -->
<!-- field: name -->

The name identifies the node type in the [codebook](https://documentation.networkcanvas.com/en/design-protocols/key-concepts/codebook) and in your exported data, for example _Person_, _Organization_ or _Place_.

## Choose how the type looks

<!-- dialog: create new node type | edit this node type -->
<!-- field: color -->

Nodes of this type are drawn in the color and shape you choose throughout the interview. On stages with an add button, the type's icon appears on that button.
