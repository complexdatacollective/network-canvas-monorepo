## Offer nodes from elsewhere

<!-- section: Side panels -->
<!-- scene: name-generator-panel-sources -->

A side panel lists nodes beside the question, so the participant can drag them in instead of typing them again. Each panel takes its nodes from one of two sources:

- **The interview so far**: alters already named on earlier stages or prompts. Use this when several prompts may name the same alters, so that the participant can add an existing alter to another prompt without creating a duplicate.
- **A network data file**: a roster you import, such as the members of a class or team. Every participant sees the same list. Dragging an entry in removes it from the panel, so each entry can be added only once.

A stage can have up to two panels, for example one listing alters already named and one listing a roster. A panel's filter applies to every prompt of this stage.

Read more about [working with roster data](https://documentation.networkcanvas.com/design-protocols/tutorials/working-with-rosters).
