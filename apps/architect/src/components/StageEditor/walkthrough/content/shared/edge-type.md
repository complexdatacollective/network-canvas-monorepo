## Choose the edge type

<!-- section: edge-type -->
<!-- scene: edge-form-source -->

Choose the **edge type** this stage works with, such as _Friends_. The stage uses the edges of that type already in the participant's network. If there are none, the stage is skipped.

Changing the edge type later clears this stage's other settings, because they depend on the edge type.
