## Name the edge type

<!-- dialog: create new edge type | edit this edge type -->
<!-- field: name -->

An edge type represents one kind of relationship between nodes, such as _Knows_, _Works with_ or _Dislikes_. The name identifies the edge type in the [codebook](https://documentation.networkcanvas.com/design-protocols/key-concepts/codebook) and in the edge list of your exported data.

## Choose the edge color

<!-- dialog: create new edge type | edit this edge type -->
<!-- field: color -->

Edges of this type are drawn in this color throughout the interview, so that participants can tell one kind of relationship from another when several are shown together.

> Do: Consider mapping important themes in your interview to a consistent color, to create visual associations.

> Avoid: Using the same color for multiple edge types. The participant will not be able to tell them apart.
