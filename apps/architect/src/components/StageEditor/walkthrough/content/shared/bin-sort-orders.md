## Order the alters in the drawer

<!-- dialog: create prompt | edit prompt -->
<!-- scene: bin-bucket-order -->

Switch on **Bucket order** to set the order alters wait in the drawer, by one or more attributes, such as by name. Without rules, they wait in the order they were added.

## Order the alters in each bin

<!-- dialog: create prompt | edit prompt -->

Switch on **Bin order** to set the order alters are listed in once they are in a bin. Choose the asterisk property to list them in the order they were placed.
