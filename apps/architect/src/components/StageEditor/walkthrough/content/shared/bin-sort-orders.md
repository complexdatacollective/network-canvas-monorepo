## Order the alters in the drawer

<!-- dialog: create prompt | edit prompt -->
<!-- scene: bin-bucket-order -->

Switch on **Bucket order** to sort the alters in the drawer by one or more attributes, such as name. Without sort rules, the alters stay in the order they were added.

## Order the alters in each bin

<!-- dialog: create prompt | edit prompt -->

Switch on **Bin order** to set the order alters are listed in once they are in a bin. To list them in the order the participant placed them, choose the property shown as `*`.
