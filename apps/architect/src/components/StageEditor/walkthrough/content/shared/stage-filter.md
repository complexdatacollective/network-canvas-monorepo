## Show only some nodes

<!-- section: Stage filter -->
<!-- scene: stage-filter -->

Switch on **Stage filter** to include only some nodes on this stage, for example only nodes whose `close_friend` attribute is true. Without a filter, every node of the chosen type appears.

Read more about [network filtering](https://documentation.networkcanvas.com/en/design-protocols/key-concepts/network-filtering).
