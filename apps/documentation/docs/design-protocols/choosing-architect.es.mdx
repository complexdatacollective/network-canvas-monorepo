Architect es el diseñador de protocolos de Network Canvas: la herramienta que usas para crear los protocolos de entrevista que se ejecutan en Interviewer y en Fresco. Tiene dos versiones: una aplicación web que funciona en tu navegador y que se puede instalar para usarla sin conexión, y **Architect Classic**, la aplicación de escritorio anterior, que se descarga (para Windows, macOS y Linux). En toda esta documentación, «Architect» a secas se refiere a la aplicación web, y «Architect Classic» siempre se refiere a la versión descargable. Las dos comparten las mismas pantallas y la misma forma de crear protocolos, pero **no son intercambiables**: cada una crea una versión distinta del formato de archivo de protocolo (el «esquema»), y esa versión determina en qué aplicación puedes realizar tus entrevistas. En la tabla siguiente se comparan; cuál debes usar depende sobre todo de dónde vayas a realizar tus entrevistas.

<KeyConcept title="¿No sabes cuál usar?">

Elige **Architect** para los estudios nuevos: es la opción predeterminada y no requiere ninguna configuración. Sus protocolos (del esquema 9) se ejecutan en **Fresco** y en la nueva aplicación **Interviewer**.

Elige **Architect Classic** solo si necesitas seguir usando **Interviewer Classic**, la aplicación anterior para ordenador y tableta. Crea protocolos del esquema 7 y no puede abrir protocolos creados en Architect.

[Abrir Architect →](https://architect.networkcanvas.com)

</KeyConcept>

|                                | Architect                                                           | Architect Classic                                                                                                          |
| ------------------------------ | ------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| Instalación                    | Ninguna: funciona en el navegador                                   | Hay que descargarlo e instalarlo (Windows, macOS, Linux)                                                                   |
| Esquema de protocolo           | Esquema 9 (el más reciente)                                         | Esquema 7 y anteriores                                                                                                     |
| Las entrevistas se realizan en | Fresco e Interviewer                                                | Interviewer Classic (Interviewer y Fresco migran automáticamente al esquema 8 los protocolos creados en Architect Classic) |
| Copias de seguridad y traslado | Descarga un archivo `.netcanvas` para guardar o compartir una copia | Tu archivo `.netcanvas` ya está en el disco: cópialo donde quieras                                                         |
| Actualizaciones                | Siempre la versión más reciente, automáticamente                    | Tienes que descargar tú cada nueva versión                                                                                 |
| Recomendado para               | Estudios nuevos (que se realizan en Fresco o Interviewer)           | Estudios que tienen que seguir usando la aplicación anterior, Interviewer Classic                                          |
| Estado                         | En desarrollo activo                                                | En mantenimiento: solo corrección de errores                                                                               |

<TipBox>

Una **PWA** (aplicación web progresiva) es un sitio web que, si quieres, puedes instalar en tu dispositivo. Architect funciona en cualquier navegador web moderno sin necesidad de instalar nada; instalarlo como PWA te permite abrirlo rápidamente desde tu dispositivo y usarlo sin conexión.

</TipBox>

Architect abre protocolos creados para versiones anteriores del esquema, incluidos los protocolos del esquema 7 creados en Architect Classic. Te ofrece actualizar un protocolo antiguo a la versión más reciente del esquema o seguir editándolo como esquema 8 en la versión anterior de Architect, que viene incluida. La actualización no tiene vuelta atrás: un protocolo actualizado no se puede revertir a una versión anterior del esquema ni abrir en Architect Classic. Para ver una explicación completa de las versiones del esquema y de la compatibilidad, consulta [Información sobre el esquema de protocolo](/es/get-started/protocol-schema-information). Si vuelves a Network Canvas después de haber usado las aplicaciones Classic, [Migrar desde las aplicaciones Classic](/es/get-started/migrating-from-classic) explica todo el cambio de principio a fin: el protocolo, los datos y lo que cambia en el trabajo diario.
