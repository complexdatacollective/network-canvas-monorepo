¿No sabes si de verdad necesitas Architect Classic? Consulta [Elegir Architect o Architect Classic](/es/design-protocols/choosing-architect).

Para todos los estudios nuevos, te recomendamos usar [Architect](/es/design-protocols/getting-started), que funciona completamente en tu navegador sin necesidad de descargar ni instalar nada (y que se puede instalar como aplicación web progresiva para usarlo sin conexión). Crea protocolos del esquema 9, que se pueden usar en [Fresco](/es/collect-data/fresco/about) y en [Interviewer](/es/collect-data/interviewer/about).

No obstante, si necesitas crear un protocolo del esquema 7, puedes usar **Architect Classic**. Se puede descargar e instalar por separado desde la [página de descarga](https://networkcanvas.com/es/get-started): para usarlo no necesitas instalar ninguna de las otras aplicaciones de Network Canvas.

## Requisitos del sistema {#system-requirements}

Architect Classic solo es compatible con Windows 10 (1909) o posterior y con macOS 10.15.4 o posterior. También se ofrecen paquetes para Linux (consulta más abajo).

Recomendamos un dispositivo moderno, con una pantalla de alta resolución (más de 900 píxeles de resolución vertical efectiva), memoria RAM abundante y tarjeta gráfica dedicada. El rendimiento puede variar considerablemente según la potencia del dispositivo que uses.

Puedes instalar y ejecutar el software en dispositivos que no cumplan estos requisitos, pero, lamentablemente, en ese caso no podemos ofrecer asistencia con los problemas técnicos.

## Windows {#windows}

Visita la [página de descarga](https://networkcanvas.com/es/get-started) y descarga la versión de Architect Classic para Windows.

Abre el archivo .exe. Es posible que aparezca un cuadro de diálogo que indica que la aplicación no se puede ejecutar porque procede de un editor sin firma. Esto ocurre porque nuestras aplicaciones todavía no han acumulado suficiente confianza ante Microsoft para superar estos filtros automáticamente. Esto cambiará a medida que más personas instalen nuestras aplicaciones.

Para continuar con la instalación, haz clic en el texto «Más información» del cuadro de diálogo. A continuación, debería aparecer el botón «Ejecutar de todas formas». Una vez instalada, la aplicación debería abrirse inmediatamente. También deberías poder encontrarla en la lista de programas del menú Inicio.

## macOS {#macos}

Visita la [página de descarga](https://networkcanvas.com/es/get-started) y descarga la versión de Architect Classic para macOS. Se distribuye como imagen de disco DMG.

Al hacer doble clic en el archivo DMG, se abre una nueva ventana del Finder con el icono de la aplicación y una carpeta que representa la carpeta «Aplicaciones» de tu ordenador. Arrastra la aplicación a la carpeta Aplicaciones. Si se te pide que te autentiques y no tienes credenciales para hacerlo, puedes simplemente arrastrar la aplicación a cualquier ubicación dentro de tu carpeta de inicio.

Una vez instalada la aplicación, tendrás que hacer doble clic en su icono para abrirla.

## Linux {#linux}

Ofrecemos paquetes para Linux en varios formatos, tanto para la arquitectura x86 como para ARM. Visita la [página de descarga](https://networkcanvas.com/es/get-started) y haz clic en el enlace para descargar Architect Classic para Linux. Se te redirigirá a la versión más reciente en GitHub, donde encontrarás los archivos de los paquetes. Consulta la documentación de tu distribución para saber qué formatos de paquete admite y cómo instalarlos.

Si tienes dificultades para instalar o ejecutar estos paquetes, ponte en contacto con el equipo del proyecto.

**Ten en cuenta que ya no admitimos el formato de paquete SNAP, debido a las dificultades del proceso de compilación. Si usas versiones anteriores del software que se distribuían en este formato, actualiza a uno de los paquetes que se ofrecen actualmente.**
