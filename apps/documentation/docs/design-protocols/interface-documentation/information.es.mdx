La interfaz «Información» es una pantalla de uso general que sirve para presentar información a quienes participan mediante diversos recursos de texto y multimedia. Por ejemplo, esta pantalla puede ser útil para presentar un estudio o para dar instrucciones o contexto sobre una etapa concreta de la encuesta.

En una etapa «Información», puedes incorporar uno o varios [recursos](/es/design-protocols/key-concepts/resources), ya sea tomando archivos de tu biblioteca de recursos de Architect o directamente desde tu dispositivo. No hay límite en el número de elementos: quienes participan pueden desplazarse por la pantalla, así que añade todos los que necesites.

## Configurar la etapa «Información» {#configuring-information-screen}

Una etapa «Información» consta de un encabezado de página obligatorio, seguido de una columna de elementos que se muestran de arriba abajo. Cada elemento puede ser texto, una imagen, un vídeo o un audio, y una etapa necesita al menos uno. Los elementos se pueden reordenar arrastrándolos. A las imágenes y los vídeos se les puede asignar un tamaño de visualización: **Tamaño completo** los muestra con su altura natural, mientras que **Pequeño**, **Mediano** y **Grande** limitan la altura con la que se dibujan, manteniendo sus proporciones.

### Buenas prácticas {#best-practices}

<GoodPractice>

Usa esta interfaz para explicar a quienes participan las actividades de las etapas, de modo que las comprendan mejor y se impliquen más. Esto puede ser especialmente importante para mejorar la accesibilidad de la encuesta.

</GoodPractice>

### Qué evitar {#try-to-avoid}

<BadPractice>

No sobrecargues la interfaz con texto; en su lugar, plantéate usar otros tipos de recursos para comunicar la información a quienes participan.

</BadPractice>
