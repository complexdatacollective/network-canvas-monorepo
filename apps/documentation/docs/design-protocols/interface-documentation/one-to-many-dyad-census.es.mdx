Esta interfaz es una variante de la interfaz «Censo de díadas» que permite a quienes participan crear vínculos entre un álter (cada persona a la que se nombra durante la entrevista) y varios otros álteres. Es especialmente útil para recoger vínculos cuando un álter tiene relaciones con muchos otros, como una figura central de una red.

La interfaz permite configurar si el «nodo focal» vuelve a la lista principal de nodos después de haberse evaluado o si se elimina de la lista (la opción predeterminada).

### Buenas prácticas {#best-practices}

<GoodPractice>

Usa esta interfaz para animar a quienes participan a añadir vínculos que quizá no habían tenido en cuenta, sobre todo cuando un álter tiene relaciones con varios otros.

</GoodPractice>

<GoodPractice>

Usa esta interfaz en lugar de la interfaz «Censo de díadas» estándar cuando esperes que un álter tenga muchas relaciones con otros, ya que simplifica el proceso para quienes participan.

</GoodPractice>

### Qué evitar {#try-to-avoid}

<BadPractice>

Usar esta interfaz con un gran número de álteres sigue dando lugar a muchas pantallas: hay una pantalla por cada nodo focal, así que el número de pantallas crece en proporción al número de álteres. Si tienes muchos álteres, plantéate usar otros métodos para recoger los vínculos, como la interfaz [«Sociograma»](/es/design-protocols/interface-documentation/sociogram).

</BadPractice>
