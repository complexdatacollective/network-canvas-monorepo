L’interface « Formulaire ego » est une interface qui recueille des données sur l’ego (la personne participante, au centre de son réseau). Dans une étape « Formulaire ego », les personnes participantes remplissent un [formulaire](../key-concepts/forms) les concernant, composé d’un ou de plusieurs champs. Cette interface comporte aussi un panneau d’introduction intégré, dans lequel le but du formulaire peut être expliqué à la personne participante.

## Configurer une étape « Formulaire ego » {#configuring-ego-form}

Le [formulaire](../key-concepts/forms) configurable détermine les attributs qui seront enregistrés dans la partie ego du réseau.

![](/assets/img/interface-documentation/ego-form/architect-ego-form.png)

### Bonnes pratiques {#best-practices}

<GoodPractice>

Utilisez cette interface comme moyen simple de recueillir des données d’attributs sur chaque personne participante de votre étude.

</GoodPractice>

<GoodPractice>

Envisagez de placer cette interface vers le début de votre enquête, pour recueillir des données sur la personne participante avant de lui demander de fournir des données sur les personnes de son réseau.

</GoodPractice>

### À éviter {#try-to-avoid}

<BadPractice>

Évitez de surcharger le formulaire avec trop de champs et/ou des consignes chargées de texte, qui rendent l’interface fastidieuse à remplir.

</BadPractice>
