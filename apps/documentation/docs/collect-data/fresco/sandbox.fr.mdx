Nous avons créé un [déploiement de Fresco qui sert de bac à sable](https://fresco-sandbox.networkcanvas.com) pour vous permettre de découvrir la plateforme Fresco sans configurer votre propre instance.

Le bac à sable est aussi un bon moyen de vous exercer à la collecte de données à distance dans le cadre d’une répétition générale plus large de votre étude : consultez [Mener une étude pilote](/fr/get-started/planning-a-study/piloting-your-study).

**Le bac à sable est un environnement d’exemple partagé, qui n’est pas destiné à de vrais entretiens.**

L’utilisation du bac à sable n’est soumise à aucune restriction, mais nous réinitialisons périodiquement sa base de données. Toutes les données que vous téléversez (envoyez vers le serveur) seront donc supprimées.

<TipBox danger>

Tous les fichiers de protocole téléversés sont visibles par toutes les personnes qui utilisent le bac à sable. Faites attention aux données que vous téléversez.

**Ne téléversez en aucun cas de vraies données d’étude ni de vraies données de personnes participantes.**

</TipBox>

## Accéder au bac à sable {#accessing-the-sandbox}

Pour accéder au bac à sable, rendez-vous sur [https://fresco-sandbox.networkcanvas.com](https://fresco-sandbox.networkcanvas.com) et utilisez les identifiants de connexion suivants :

- **Nom d’utilisateur** : `admin`
- **Mot de passe** : `Administrator1!`
