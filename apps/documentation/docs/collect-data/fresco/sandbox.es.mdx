Hemos creado una [implementación de Fresco que sirve de entorno de pruebas](https://fresco-sandbox.networkcanvas.com) para que puedas explorar la plataforma Fresco sin configurar tu propia instancia.

El entorno de pruebas también es una buena forma de practicar la recopilación de datos a distancia como parte de un ensayo general más amplio de tu estudio; consulta [Realizar un estudio piloto](/es/get-started/planning-a-study/piloting-your-study).

**El entorno de pruebas es una implementación de ejemplo compartida que no está pensada para realizar entrevistas reales.**

No hay restricciones de uso del entorno de pruebas, pero restableceremos periódicamente la base de datos. Esto significa que se eliminarán todos los datos que subas.

<TipBox danger>

Todas las personas que usan el entorno de pruebas podrán ver los archivos de protocolo que se suban. Ten cuidado con los datos que subes.

**En ningún caso deben subirse datos reales de un estudio ni de participantes.**

</TipBox>

## Acceder al entorno de pruebas {#accessing-the-sandbox}

Para acceder al entorno de pruebas, visita [https://fresco-sandbox.networkcanvas.com](https://fresco-sandbox.networkcanvas.com) e introduce las siguientes credenciales:

- **Nombre de usuario**: `admin`
- **Contraseña**: `Administrator1!`
