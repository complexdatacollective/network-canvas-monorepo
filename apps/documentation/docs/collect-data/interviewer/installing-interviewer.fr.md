Interviewer exécute vos protocoles Network Canvas et collecte des données sur le terrain. Vous n’avez besoin d’aucune des autres applications Network Canvas pour l’utiliser.

Interviewer existe en deux versions prises en charge, que vous obtenez de manière différente :

- **Interviewer** — fonctionne dans votre **navigateur web**, sans rien avoir à télécharger. Ouvrez-le à l’adresse [interviewer.networkcanvas.com](https://interviewer.networkcanvas.com) et, si vous le souhaitez, installez-le comme **application web progressive (PWA)** sur un appareil dont vous avez le contrôle, pour y accéder rapidement et l’utiliser hors ligne. Construit sur la même plateforme que Fresco 4.0, il prend en charge les protocoles en schéma 8 et 9, est compatible avec vos protocoles existants et est recommandé pour les nouvelles études.
- **Interviewer Classic** — l’application éprouvée pour **ordinateur et tablette**. Téléchargez-la et installez-la depuis la [page de téléchargement](https://networkcanvas.com/fr/get-started). Elle exécute les protocoles en schéma 7 et fonctionne entièrement hors ligne.

## Utiliser Interviewer dans le navigateur {#using-interviewer-in-the-browser}

Ouvrez [interviewer.networkcanvas.com](https://interviewer.networkcanvas.com) dans un navigateur web récent : il n’y a rien à télécharger ni à installer, et vous utilisez toujours la dernière version de l’application. Pour l’avoir sous la main sur un appareil d’entretien, utilisez l’option **Installer** de votre navigateur (souvent présentée sous la forme d’une icône d’installation dans la barre d’adresse, ou « Ajouter à l’écran d’accueil ») pour l’installer comme application web progressive. L’application s’ouvre alors dans sa propre fenêtre, apparaît à côté de vos autres applications et reste disponible hors ligne. Toutes les langues de l’interface sont enregistrées avec l’application installée : vous pouvez donc aussi changer de langue hors ligne.

Les performances de l’entretien dépendent de l’appareil sur lequel vous exécutez Interviewer. Pour des conseils sur le choix d’un appareil qui offrira aux personnes participantes une expérience d’entretien fluide, consultez [Choisir un appareil pour Interviewer](/fr/collect-data/interviewer/choosing-hardware).

### Navigateurs pris en charge {#supported-browsers}

Interviewer est pris en charge sur les dernières versions de Chrome, Safari et Firefox. Comme Interviewer est construit sur la même plateforme que Fresco, les navigateurs pris en charge sont les mêmes pour les deux applications. Internet Explorer et Edge Legacy sont expressément exclus de la prise en charge.

## Installer Interviewer Classic {#installing-interviewer-classic}

**Interviewer Classic** est l’application téléchargeable pour ordinateur et tablette, disponible sur la [page de téléchargement](https://networkcanvas.com/fr/get-started). Installez-la sur chaque appareil que vous utiliserez pour mener des entretiens avec les personnes participantes.

### Configuration requise {#system-requirements}

Interviewer Classic n’est pris en charge que sous Windows 10 (1909) ou version ultérieure, macOS 10.15.4 ou version ultérieure, Android 10 ou version ultérieure et iPadOS 14.2 ou version ultérieure.

Nous recommandons un appareil récent, doté d’un écran haute résolution (plus de 900 pixels de résolution verticale effective), d’une grande quantité de mémoire vive et d’une carte graphique dédiée. Les performances peuvent varier considérablement selon la puissance de l’appareil que vous utilisez, et vous devez savoir que cela peut nuire à l’expérience d’entretien des personnes participantes à votre recherche, et donc à la qualité des données.

Vous pouvez installer et exécuter le logiciel sur des appareils qui ne répondent pas à ces critères, mais nous ne pourrons malheureusement pas vous apporter d’assistance en cas de problème technique.

### Windows {#windows}

Rendez-vous sur la [page de téléchargement](https://networkcanvas.com/fr/get-started) et téléchargez la version Windows d’Interviewer Classic.

Ouvrez le fichier .exe. Une boîte de dialogue peut vous indiquer que l’application ne peut pas être exécutée parce qu’elle n’est pas signée et provient d’un éditeur inconnu. Cela s’explique par le fait que nos applications n’ont pas encore acquis suffisamment de confiance auprès de Microsoft pour passer automatiquement ces filtres. Cela évoluera à mesure que davantage de personnes installeront nos applications.

Pour poursuivre l’installation de l’application, cliquez simplement sur le texte « Informations complémentaires » dans la boîte de dialogue. Un bouton « Exécuter quand même » devrait alors apparaître. Une fois installée, l’application devrait s’ouvrir immédiatement. Vous devriez également la trouver dans la liste des programmes du menu Démarrer.

### macOS {#macos}

Rendez-vous sur la [page de téléchargement](https://networkcanvas.com/fr/get-started) et téléchargez la version macOS d’Interviewer Classic. Elle se présente sous la forme d’une image disque DMG.

Lorsque vous double-cliquez sur le fichier DMG, une nouvelle fenêtre du Finder s’ouvre avec l’icône de l’application et un dossier qui représente le dossier « Applications » de votre ordinateur. Faites glisser l’application dans le dossier Applications. Si une authentification vous est demandée et que vous ne disposez pas des identifiants nécessaires, vous pouvez simplement faire glisser l’application à n’importe quel endroit de votre dossier de départ.

Une fois l’application installée, double-cliquez sur son icône pour ouvrir le programme.

### Linux {#linux}

Nous proposons des paquets Linux dans plusieurs formats, pour les architectures x86 et ARM. Rendez-vous sur la [page de téléchargement](https://networkcanvas.com/fr/get-started) et cliquez sur le lien de téléchargement d’Interviewer Classic pour Linux. Ce lien vous mène à la version la plus récente sur GitHub, où se trouvent les fichiers des paquets eux-mêmes. Consultez la documentation de votre distribution pour savoir quels formats de paquets sont pris en charge et comment les installer.

Si vous rencontrez des difficultés pour installer ou exécuter ces paquets, contactez l’équipe du projet.

**Notez que nous ne prenons plus en charge le format de paquet SNAP, en raison de difficultés liées au processus de compilation. Si vous utilisez des versions antérieures du logiciel distribuées dans ce format, passez à l’un des paquets actuellement pris en charge.**

### Android {#android}

L’installation sur les appareils Android se déroule comme pour n’importe quelle autre application Android. Pour trouver Interviewer Classic, ouvrez l’application Play Store et recherchez « Network Canvas Interviewer ». Vous pouvez aussi vous rendre sur le [site web du Play Store](https://play.google.com/store/apps/details?id=org.codaco.NetworkCanvasInterviewer6) et lancer l’installation sur vos appareils depuis celui-ci.

Notez qu’Interviewer Classic nécessite Android 10 ou une version ultérieure, et qu’il fonctionne mieux sur les grandes tablettes (9,7 pouces ou plus). L’installation est limitée aux appareils qui répondent à ces critères.

Si vous ne trouvez pas Interviewer Classic dans le Play Store, c’est probablement parce que votre appareil n’est pas compatible. Si vous pensez que votre appareil devrait être compatible et que vous ne trouvez toujours pas l’application dans le Play Store, contactez-nous.

### ChromeOS {#chromeos}

Si votre appareil ChromeOS permet d’installer des applications Android, vous pouvez installer Interviewer Classic comme d’habitude depuis le Google Play Store. Pour cela, consultez les instructions ci-dessus pour installer l’application sur Android.

Notez que seul Interviewer Classic est spécifiquement conçu pour fonctionner sous ChromeOS, et uniquement lorsqu’il est exécuté comme application Android. L’exécution d’Interviewer Classic au moyen de la compatibilité avec les applications Linux n’est pas prise en charge pour le moment.
