Interviewer ejecuta tus protocolos de Network Canvas y recopila datos sobre el terreno. Para usarlo no necesitas ninguna de las otras aplicaciones de Network Canvas.

Interviewer tiene dos versiones admitidas, y cada una se obtiene de una forma distinta:

- **Interviewer**: funciona en tu **navegador web**, sin descargar nada. Ábrelo en [interviewer.networkcanvas.com](https://interviewer.networkcanvas.com) y, si quieres, instálalo como **aplicación web progresiva (PWA)** en un dispositivo que tú controlas para acceder a él rápidamente y usarlo sin conexión. Está desarrollado sobre la misma plataforma que Fresco 4.0, admite protocolos de los esquemas 8 y 9, es compatible con tus protocolos actuales y es el recomendado para los estudios nuevos.
- **Interviewer Classic**: la aplicación ya consolidada para **ordenador y tableta**. Descárgala e instálala desde la [página de descarga](https://networkcanvas.com/es/get-started). Ejecuta protocolos del esquema 7 y funciona completamente sin conexión.

## Usar Interviewer en el navegador {#using-interviewer-in-the-browser}

Abre [interviewer.networkcanvas.com](https://interviewer.networkcanvas.com) en un navegador web moderno: no hay que descargar ni instalar nada, y la aplicación siempre ejecuta la versión más reciente. Para tenerlo a mano en un dispositivo de entrevista, usa la opción **Instalar** de tu navegador (que a menudo aparece como un icono de instalación en la barra de direcciones, o como «Añadir a pantalla de inicio») para instalarlo como aplicación web progresiva. A partir de entonces se abre en su propia ventana, aparece junto a tus demás aplicaciones y sigue disponible sin conexión. Todos los idiomas de la aplicación se guardan junto con la aplicación instalada, así que también puedes cambiar de idioma sin conexión.

El rendimiento de la entrevista depende del dispositivo en el que ejecutes Interviewer. Para ver consejos sobre cómo elegir un dispositivo que ofrezca a quienes participan una experiencia de entrevista fluida, consulta [Elegir un dispositivo para Interviewer](/es/collect-data/interviewer/choosing-hardware).

### Navegadores compatibles {#supported-browsers}

Interviewer es compatible con las versiones más recientes de Chrome, Safari y Firefox. Como Interviewer está desarrollado sobre la misma plataforma que Fresco, los navegadores compatibles son los mismos para ambas aplicaciones. En concreto, no son compatibles Internet Explorer ni Edge Legacy.

## Instalar Interviewer Classic {#installing-interviewer-classic}

**Interviewer Classic** es la aplicación descargable para ordenador y tableta, disponible en la [página de descarga](https://networkcanvas.com/es/get-started). Instálala en todos los dispositivos que vayas a usar para entrevistar a participantes.

### Requisitos del sistema {#system-requirements}

Interviewer Classic solo es compatible con Windows 10 (1909) o posterior, macOS 10.15.4 o posterior, Android 10 o posterior e iPadOS 14.2 o posterior.

Recomendamos un dispositivo moderno, con una pantalla de alta resolución (más de 900 píxeles de resolución vertical efectiva), memoria RAM abundante y tarjeta gráfica dedicada. El rendimiento puede variar considerablemente según la potencia del dispositivo que uses, y debes tener en cuenta que esto puede perjudicar la experiencia de entrevista de quienes participan en tu investigación, lo que se traduce en datos de peor calidad.

Puedes instalar y ejecutar el software en dispositivos que no cumplan estos requisitos, pero, lamentablemente, en ese caso no podemos ofrecer asistencia con los problemas técnicos.

### Windows {#windows}

Visita la [página de descarga](https://networkcanvas.com/es/get-started) y descarga la versión de Interviewer Classic para Windows.

Abre el archivo .exe. Es posible que aparezca un cuadro de diálogo que indica que la aplicación no se puede ejecutar porque procede de un editor sin firma. Esto ocurre porque nuestras aplicaciones todavía no han acumulado suficiente confianza ante Microsoft para superar estos filtros automáticamente. Esto cambiará a medida que más personas instalen nuestras aplicaciones.

Para continuar con la instalación, haz clic en el texto «Más información» del cuadro de diálogo. A continuación, debería aparecer el botón «Ejecutar de todas formas». Una vez instalada, la aplicación debería abrirse inmediatamente. También deberías poder encontrarla en la lista de programas del menú Inicio.

### macOS {#macos}

Visita la [página de descarga](https://networkcanvas.com/es/get-started) y descarga la versión de Interviewer Classic para macOS. Se distribuye como imagen de disco DMG.

Al hacer doble clic en el archivo DMG, se abre una nueva ventana del Finder con el icono de la aplicación y una carpeta que representa la carpeta «Aplicaciones» de tu ordenador. Arrastra la aplicación a la carpeta Aplicaciones. Si se te pide que te autentiques y no tienes credenciales para hacerlo, puedes simplemente arrastrar la aplicación a cualquier ubicación dentro de tu carpeta de inicio.

Una vez instalada la aplicación, tendrás que hacer doble clic en su icono para abrirla.

### Linux {#linux}

Ofrecemos paquetes para Linux en varios formatos, tanto para la arquitectura x86 como para ARM. Visita la [página de descarga](https://networkcanvas.com/es/get-started) y haz clic en el enlace para descargar Interviewer Classic para Linux. Se te redirigirá a la versión más reciente en GitHub, donde encontrarás los archivos de los paquetes. Consulta la documentación de tu distribución para saber qué formatos de paquete admite y cómo instalarlos.

Si tienes dificultades para instalar o ejecutar estos paquetes, ponte en contacto con el equipo del proyecto.

**Ten en cuenta que ya no admitimos el formato de paquete SNAP, debido a las dificultades del proceso de compilación. Si usas versiones anteriores del software que se distribuían en este formato, actualiza a uno de los paquetes que se ofrecen actualmente.**

### Android {#android}

La instalación en dispositivos Android funciona igual que con cualquier otra aplicación de Android. Para encontrar Interviewer Classic, abre la aplicación Play Store y busca «Network Canvas Interviewer». También puedes visitar el [sitio web de Play Store](https://play.google.com/store/apps/details?id=org.codaco.NetworkCanvasInterviewer6) e iniciar desde allí la instalación en tus dispositivos.

Ten en cuenta que Interviewer Classic requiere Android 10 o posterior, y funciona mejor en tabletas grandes (de 9,7" o más). Solo se puede instalar en dispositivos que cumplan estos requisitos.

Si no encuentras Interviewer Classic en Play Store, lo más probable es que tu dispositivo no sea compatible. Si crees que tu dispositivo debería ser compatible y aun así no encuentras la aplicación en Play Store, ponte en contacto con nosotros.

### ChromeOS {#chromeos}

Si tu dispositivo ChromeOS admite la instalación de aplicaciones de Android, puedes instalar Interviewer Classic como de costumbre a través de Google Play Store. Para ello, consulta las instrucciones anteriores para instalar la aplicación en Android.

Ten en cuenta que solo Interviewer Classic está diseñado específicamente para funcionar con ChromeOS, y solo cuando se ejecuta como aplicación de Android. Por el momento, no se admite ejecutar Interviewer Classic mediante la compatibilidad con aplicaciones de Linux.
