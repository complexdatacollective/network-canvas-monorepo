Una vez que has recopilado datos con Interviewer o Fresco, el siguiente paso es
sacarlos de la aplicación y llevarlos a las herramientas que usas para el
análisis. Network Canvas exporta tus entrevistas en formatos estandarizados y
bien documentados, para que puedas trabajar con ellas en R, en Python o en el
paquete de análisis de redes que prefieras.

En esta sección se explica cómo exportar tus datos, qué formatos de archivo
genera Network Canvas y cómo cargar esos datos y trabajar con ellos en los
entornos de análisis más habituales.

<KeyConcept title="Por dónde empezar">

Si es la primera vez que trabajas con datos de Network Canvas, empieza por
[Exportación de datos](/es/analyze-data/data-export) para conocer los formatos
disponibles y, después, lee
[Trabajar con datos de Network Canvas en R](/es/analyze-data/working-with-data)
para seguir un ejemplo práctico paso a paso.

</KeyConcept>

El resto de la sección contiene material de referencia: el
[diccionario de datos de exportación](/es/analyze-data/data-dictionary) muestra
exactamente cómo aparece cada tipo de variable en los archivos CSV y GraphML
exportados; el apartado
[Extensiones GraphML de Network Canvas](/es/analyze-data/data-export#network-canvas-graphml-extensions)
de la página «Exportación de datos» documenta las extensiones de esquema que
se usan en los archivos GraphML exportados, y la página
[API de Fresco](/es/analyze-data/fresco-api) describe cómo obtener datos
automáticamente de tus instancias de Fresco.
