Une fois les données recueillies avec Interviewer ou Fresco, l’étape suivante
consiste à les sortir de l’application pour les amener dans les outils que vous
utilisez pour l’analyse. Network Canvas exporte vos entretiens dans des formats
standardisés et bien documentés, afin que vous puissiez les exploiter dans R,
dans Python ou dans le logiciel d’analyse de réseaux de votre choix.

Cette section explique comment exporter vos données, quels formats de fichier
Network Canvas produit, et comment charger ces données et les exploiter dans
les environnements d’analyse courants.

<KeyConcept title="Par où commencer">

Si vous découvrez les données Network Canvas, commencez par la page
[Exportation des données](/fr/analyze-data/data-export) pour connaître les
formats disponibles, puis lisez
[Travailler avec les données Network Canvas dans R](/fr/analyze-data/working-with-data)
pour une présentation pratique, pas à pas.

</KeyConcept>

Le reste de cette section contient des documents de référence : le
[dictionnaire des données exportées](/fr/analyze-data/data-dictionary) montre
précisément comment chaque type de variable apparaît dans les fichiers CSV et
GraphML exportés ; la partie
[Extensions GraphML de Network Canvas](/fr/analyze-data/data-export#network-canvas-graphml-extensions)
de la page « Exportation des données » documente les extensions de schéma
utilisées dans les fichiers GraphML exportés ; enfin, la page
[API de Fresco](/fr/analyze-data/fresco-api) décrit comment récupérer
automatiquement des données depuis vos instances de Fresco.
