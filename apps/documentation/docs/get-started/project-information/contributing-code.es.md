## Aportar código a Network Canvas {#contributing-code-to-network-canvas}

Agradecemos cualquier aportación de código, por pequeña que sea. Puede tratarse de correcciones de errores, funciones nuevas o mejoras de las funciones existentes. (Todavía) no tenemos una guía formal para contribuir con código. Ponte en contacto con nosotros en GitHub si tienes preguntas concretas sobre cuestiones técnicas.

Evaluaremos todas las solicitudes de incorporar código a los repositorios principales según los siguientes criterios:

1. Sostenibilidad de la aportación propuesta. Es imprescindible que ninguna aportación perjudique la sostenibilidad general del proyecto. Entre los factores que pueden afectarla están la centralización, el uso de servicios de terceros de pago y el uso de tecnologías obsoletas o sin mantenimiento.
2. Mantenibilidad de la aportación propuesta. Debemos poder mantener y actualizar razonablemente la aportación propuesta. Esto significa que la aportación debe tener una gran calidad técnica e ir acompañada de documentación técnica.
3. Utilidad general para quienes usan Network Canvas. La aportación propuesta debe beneficiar claramente a una parte significativa de quienes usan nuestras herramientas. Las funciones exclusivas de proyectos de investigación o experimentos concretos no son buenas candidatas para incluirse en los repositorios principales.
4. Coherencia con la finalidad del producto. La aportación propuesta debe suponer una mejora significativa de la herramienta para su finalidad prevista, que es simplificar la recopilación de datos complejos de redes.

Para que se estudie la incorporación de una aportación a los repositorios principales, todas las personas autoras deben firmar un acuerdo de cesión de derechos de autor (CTA, por sus siglas en inglés) que otorgue a CODACO la titularidad de los derechos de autor. Facilitaremos este acuerdo a quien lo solicite.

Las personas autoras tienen derecho a que se reconozcan sus aportaciones. El tipo de reconocimiento debe ser proporcional al grado de la aportación, y se tratará en cada caso según corresponda.

Las decisiones sobre la incorporación de aportaciones de código externas a los repositorios principales las toma exclusivamente la Junta Directiva de CODACO por mayoría simple. En caso de empate, la propuesta de incorporar el código externo se considera rechazada.

Para proponer código, abre una _pull request_ (PR) en el repositorio de GitHub correspondiente o publica un mensaje en el [foro de nuestra comunidad](https://community.networkcanvas.com).

## Definiciones usadas más arriba {#definitions-used-above}

### CODACO {#codaco}

Complex Data Collective (CODACO) es una entidad registrada sin ánimo de lucro cuya finalidad es diseñar, desarrollar y promover herramientas digitales que permitan a quienes investigan explorar datos estructurales complejos. Consulta los estatutos de CODACO para conocer en detalle su gobierno, la condición de miembro y sus normas: [https://complexdatacollective.org/docs/codaco-bylaws.pdf](https://complexdatacollective.org/docs/codaco-bylaws.pdf)

CODACO es la única titular de los derechos de autor del software Network Canvas.

### El software Network Canvas {#the-network-canvas-software}

El software Network Canvas consta de tres aplicaciones (Architect, Interviewer y Fresco), sus bibliotecas asociadas y su código fuente. Este software lo creó el equipo principal del proyecto Network Canvas, junto con el personal de desarrollo externo que contrató, con el apoyo de los Institutos Nacionales de Salud (NIH) de Estados Unidos (R01 DA042711).

Los repositorios del proyecto Network Canvas («repositorios principales») se encuentran en la organización de GitHub de CODACO: [https://github.com/complexdatacollective](https://github.com/complexdatacollective)
