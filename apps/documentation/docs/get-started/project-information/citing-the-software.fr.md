Nous vous demandons de bien vouloir nous citer dans les publications ou présentations issues de toute utilisation de la suite Network Canvas, ou de l’un de ses composants, dans la recherche, la pratique clinique, l’enseignement ou tout autre domaine. Vos citations du logiciel nous permettent de mesurer son impact et de suivre la manière dont il est utilisé.

## Citation principale {#primary-citation}

Les études qui ont utilisé Network Canvas pour recueillir les données de leurs personnes participantes devraient citer le logiciel Interviewer lui-même. Dans ce cas, nous recommandons :

> Complex Data Collective. Network Canvas Interviewer. 2016. <www.doi.org/10.5281/zenodo.6026548>

Une entrée BibTeX pour les personnes qui utilisent LaTeX :

```
@misc{network-canvas,
   organization = {Complex Data Collective},
   title        = {Network Canvas: Interviewer},
   url          = {https://github.com/complexdatacollective/Interviewer}
   year         = 2016
   doi          = https://doi.org/10.5281/zenodo.6026548
   }
```

## Architect {#architect}

Pour citer spécifiquement Architect, vous pouvez utiliser :

> Complex Data Collective. Network Canvas Architect. 2016. <https://doi.org/10.5281/zenodo.6026546>

## Citer la conception du logiciel {#citing-the-design-of-the-software}

Vous souhaiterez peut-être citer une publication scientifique qui décrit la conception de la suite logicielle. Dans ce cas, nous recommandons :

> Birkett M, Melville J, Janulis P, Phillips G 2nd, Contractor N, Hogan B. Network Canvas: Key decisions in the design of an interviewer-assisted network data collection software suite. Social Networks. 2021;66:114-124. <https://doi.org/10.1016/j.socnet.2021.02.003>

## Citer les évaluations du logiciel {#citing-evaluations-of-the-software}

Vous souhaiterez peut-être citer une évaluation du logiciel lorsque vous en parlez dans vos travaux de recherche ou vos demandes de financement. Dans ce cas, nous recommandons ces articles :

> Hogan, B., Melville, J., Phillips II, G., Janulis, P., Contractor, N., Mustanski, B., & Birkett, M. (2016). Evaluating the Paper-to-Screen Translation of Participant-Aided Sociograms with High-Risk Participants. In Proceedings of the 2016 Conference on Human Factors in Computing (CHI ‘16). San Jose, CA. <https://doi.org/10.1145/2858036.2858368>

> Hogan, B., Janulis, P., Phillips II, G., Melville, J., Mustanski, B., Contractor, N., & Birkett, M. Assessing the stability of ego-centered networks over time using the digital participant-aided sociogram tool Network Canvas. Network Science. (Camb Univ Press). 2020;8(2):204-222. <https://doi.org/10.1017/nws.2019.27>

## URL GitHub de Network Canvas {#network-canvas-github-urls}

Les URL des dépôts des logiciels Network Canvas sont :

- [https://github.com/complexdatacollective/network-canvas-monorepo](https://github.com/complexdatacollective/network-canvas-monorepo) : les applications Architect et Interviewer actuelles et leurs paquets partagés
- [https://github.com/complexdatacollective/Fresco](https://github.com/complexdatacollective/Fresco) : Fresco
- [https://github.com/complexdatacollective/Interviewer](https://github.com/complexdatacollective/Interviewer) et [https://github.com/complexdatacollective/Architect](https://github.com/complexdatacollective/Architect) : les applications Classic

Architect et Interviewer fonctionnent dans votre navigateur web ; pour commencer à utiliser l’un ou l’autre des outils, consultez le [guide de démarrage](/fr/get-started/network-canvas). Les applications de bureau **Classic** sont disponibles en téléchargement à l’adresse :

- [https://networkcanvas.com/get-started](https://networkcanvas.com/get-started)
