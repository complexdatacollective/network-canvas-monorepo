## Contribuer au code de Network Canvas {#contributing-code-to-network-canvas}

Toutes les contributions de code sont les bienvenues, même les plus modestes. Il peut s’agir de corrections de bogues, de nouvelles fonctionnalités ou d’améliorations de fonctionnalités existantes. Nous n’avons pas (encore) de guide formel de contribution au code. Contactez-nous sur GitHub si vous avez des questions précises d’ordre technique.

Nous évaluerons toutes les demandes d’intégration de code dans les dépôts principaux selon les critères suivants :

1. Pérennité de l’ajout proposé. Il est essentiel qu’aucune contribution ne nuise à la pérennité globale du projet. Parmi les facteurs susceptibles de l’affecter figurent la centralisation, le recours à des services tiers payants et l’utilisation de technologies obsolètes ou qui ne sont plus maintenues.
2. Maintenabilité de l’ajout proposé. Nous devons être en mesure de maintenir et de faire évoluer l’ajout proposé dans des conditions raisonnables. La contribution doit donc être d’une grande qualité technique et s’accompagner d’une documentation technique.
3. Utilité générale pour les personnes qui utilisent Network Canvas. L’ajout proposé doit présenter un avantage manifeste pour une part importante des personnes qui utilisent Network Canvas. Les fonctionnalités propres à des projets de recherche ou à des expérimentations particulières ne sont pas de bonnes candidates à une intégration dans les dépôts principaux.
4. Adéquation avec la finalité du produit. L’ajout proposé doit apporter une amélioration significative de l’outil au regard de sa finalité, qui est de simplifier le recueil de données de réseau complexes.

Pour qu’une contribution puisse être envisagée en vue de son intégration dans les dépôts principaux, toutes les personnes qui en sont autrices doivent signer un accord de cession de droits d’auteur (CTA, pour Copyright Transfer Agreement) qui confère à CODACO la qualité de titulaire des droits d’auteur. Cet accord est fourni sur demande.

Les personnes autrices ont droit à la reconnaissance de leurs contributions. La nature de cette reconnaissance doit être proportionnée à l’ampleur de la contribution, et sera discutée au cas par cas.

Les décisions d’intégrer des contributions de code externes dans les dépôts principaux sont prises exclusivement par le conseil d’administration de CODACO, à la majorité simple. En cas d’égalité des voix, la proposition d’intégrer le code externe est réputée rejetée.

Pour soumettre du code, ouvrez une _pull request_ (PR) dans le dépôt GitHub concerné, ou publiez un message sur le [forum de la communauté](https://community.networkcanvas.com).

## Définitions utilisées ci-dessus {#definitions-used-above}

### CODACO {#codaco}

Le Complex Data Collective (CODACO) est une organisation à but non lucratif enregistrée dont la mission est de concevoir, de développer et de promouvoir des outils numériques qui permettent aux équipes de recherche d’explorer des données structurelles complexes. Pour le détail de sa gouvernance, des conditions d’adhésion et de ses règles, consultez les statuts de CODACO : [https://complexdatacollective.org/docs/codaco-bylaws.pdf](https://complexdatacollective.org/docs/codaco-bylaws.pdf) (en anglais)

CODACO est l’unique titulaire des droits d’auteur du logiciel Network Canvas.

### Le logiciel Network Canvas {#the-network-canvas-software}

Le logiciel Network Canvas se compose de trois applications (Architect, Interviewer et Fresco), de leurs bibliothèques associées et de leur code source. Ce logiciel a été créé par l’équipe principale du projet Network Canvas et par des prestataires de développement externes, avec le soutien des National Institutes of Health (NIH) des États-Unis (R01 DA042711).

Les dépôts du projet Network Canvas (« dépôts principaux ») se trouvent dans l’organisation GitHub de CODACO : [https://github.com/complexdatacollective](https://github.com/complexdatacollective)
