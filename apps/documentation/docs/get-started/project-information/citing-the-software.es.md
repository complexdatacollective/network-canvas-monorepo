Te pedimos que nos cites en las publicaciones o presentaciones derivadas de cualquier uso del conjunto de herramientas Network Canvas, o de cualquiera de sus componentes, en investigación, en la práctica clínica, en la docencia o en otros ámbitos. Al citar el software, nos permites medir su impacto y conocer las formas en que se usa.

## Cita principal {#primary-citation}

Los estudios que hayan usado Network Canvas para recopilar datos de sus participantes deberían citar el propio software Interviewer. En ese caso, recomendamos:

> Complex Data Collective. Network Canvas Interviewer. 2016. <www.doi.org/10.5281/zenodo.6026548>

Una entrada de BibTeX para quienes usan LaTeX es:

```
@misc{network-canvas,
   organization = {Complex Data Collective},
   title        = {Network Canvas: Interviewer},
   url          = {https://github.com/complexdatacollective/Interviewer}
   year         = 2016
   doi          = https://doi.org/10.5281/zenodo.6026548
   }
```

## Architect {#architect}

Si quieres citar específicamente Architect, puedes usar:

> Complex Data Collective. Network Canvas Architect. 2016. <https://doi.org/10.5281/zenodo.6026546>

## Citar el diseño del software {#citing-the-design-of-the-software}

Puede que quieras citar una publicación académica que describe el diseño del conjunto de herramientas. En ese caso, recomendamos:

> Birkett M, Melville J, Janulis P, Phillips G 2nd, Contractor N, Hogan B. Network Canvas: Key decisions in the design of an interviewer-assisted network data collection software suite. Social Networks. 2021;66:114-124. <https://doi.org/10.1016/j.socnet.2021.02.003>

## Citar evaluaciones del software {#citing-evaluations-of-the-software}

Puede que quieras citar una evaluación del software al hablar de él en tu investigación o en tus solicitudes de financiación. En ese caso, recomendamos estos artículos:

> Hogan, B., Melville, J., Phillips II, G., Janulis, P., Contractor, N., Mustanski, B., & Birkett, M. (2016). Evaluating the Paper-to-Screen Translation of Participant-Aided Sociograms with High-Risk Participants. In Proceedings of the 2016 Conference on Human Factors in Computing (CHI ‘16). San Jose, CA. <https://doi.org/10.1145/2858036.2858368>

> Hogan, B., Janulis, P., Phillips II, G., Melville, J., Mustanski, B., Contractor, N., & Birkett, M. Assessing the stability of ego-centered networks over time using the digital participant-aided sociogram tool Network Canvas. Network Science. (Camb Univ Press). 2020;8(2):204-222. <https://doi.org/10.1017/nws.2019.27>

## URL de GitHub de Network Canvas {#network-canvas-github-urls}

Las URL de los repositorios del software de Network Canvas son:

- [https://github.com/complexdatacollective/network-canvas-monorepo](https://github.com/complexdatacollective/network-canvas-monorepo): las aplicaciones actuales Architect e Interviewer y sus paquetes compartidos
- [https://github.com/complexdatacollective/Fresco](https://github.com/complexdatacollective/Fresco): Fresco
- [https://github.com/complexdatacollective/Interviewer](https://github.com/complexdatacollective/Interviewer) y [https://github.com/complexdatacollective/Architect](https://github.com/complexdatacollective/Architect): las aplicaciones Classic

Architect e Interviewer funcionan en tu navegador web; para empezar a usar cualquiera de las herramientas, consulta la [guía de primeros pasos](/es/get-started/network-canvas). Las aplicaciones de escritorio **Classic** se pueden descargar en:

- [https://networkcanvas.com/get-started](https://networkcanvas.com/get-started)
