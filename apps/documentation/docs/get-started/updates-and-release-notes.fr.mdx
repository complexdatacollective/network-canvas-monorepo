## Résumé {#summary}

La [page « Nouveautés »](https://networkcanvas.com/fr/updates/) du site web de Network Canvas présente les nouveautés de chaque version d’Architect, d’Interviewer et de Fresco.

Architect et Interviewer se mettent à jour automatiquement. Pour mettre à jour Fresco, suivez le guide [Mettre à jour Fresco](/fr/collect-data/fresco/upgrading).

Pour la liste complète des modifications de chaque version, consultez les [notes de version sur GitHub](https://github.com/complexdatacollective/network-canvas-monorepo/releases) (en anglais).
