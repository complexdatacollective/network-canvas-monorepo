## Summary

The [Updates page](https://networkcanvas.com/updates) on the Network Canvas website describes what's new in each release of Architect, Interviewer, and Fresco.

Architect and Interviewer update automatically. To upgrade Fresco, follow the [Fresco upgrade guide](/en/collect-data/fresco/upgrading).

For a complete list of changes in each version, see the [release notes on GitHub](https://github.com/complexdatacollective/network-canvas-monorepo/releases).
