## Summary

The [Updates page](https://networkcanvas.com/updates) on the Network Canvas website summarizes each release of Architect, Interviewer, and Fresco in plain language: what's new, what it means for your work, and how to upgrade. You can search it for a feature, and link colleagues directly to a single update.

## Staying up to date

**Architect** and **Interviewer** update automatically. If you have installed them from your browser as Progressive Web Apps, updates load the next time you restart the app, and your local data stays on your device.

**Fresco** is hosted by your own team, so you upgrade it yourself. Follow the [Fresco upgrade guide](/en/collect-data/fresco/upgrading).

## Detailed release notes

For a complete list of changes in each version, see the [release notes on GitHub](https://github.com/complexdatacollective/network-canvas-monorepo/releases).
