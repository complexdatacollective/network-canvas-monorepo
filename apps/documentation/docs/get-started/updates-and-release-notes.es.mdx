## Resumen {#summary}

La [página de novedades](https://networkcanvas.com/es/updates/) del sitio web de Network Canvas describe qué hay de nuevo en cada versión de Architect, Interviewer y Fresco.

Architect e Interviewer se actualizan automáticamente. Para actualizar Fresco, sigue la [guía de actualización de Fresco](/es/collect-data/fresco/upgrading).

Para ver la lista completa de cambios de cada versión, consulta las [notas de la versión en GitHub](https://github.com/complexdatacollective/network-canvas-monorepo/releases).
