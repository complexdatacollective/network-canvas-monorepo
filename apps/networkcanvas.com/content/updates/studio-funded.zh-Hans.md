# NIH 资助 Network Canvas Studio

美国国家药物滥用研究所（NIDA）的一项为期五年的资助将用于开发 Network Canvas Studio，这是一个可远程、大规模收集社会网络数据的云平台，同时保持现有工具的易用性。[阅读公告](https://community.networkcanvas.com/t/95)。

<!-- more -->

### Studio 将新增哪些功能

Studio 计划包含桌面和平板应用中的全部功能，此外还将提供：

- 在任何设备的网页浏览器中进行访谈，可用于远程自填式访谈，也可在研究人员陪同下进行
- 团队共同设计、共享和编辑协议
- 可延续早期访谈数据的纵向研究
- 可与分析软件实时连接的开放 API
- 面向大型项目团队的基于角色的访问控制
- 用于安排调查和抽取参与者样本的工具
- 无障碍改进，包括多语言支持

### 由社区共同塑造

这些规划源自五年来使用 Network Canvas 的研究人员所提供的反馈，随着工作的推进，团队还将与社区开展调查和焦点小组。[在 NIH RePORTER 上查看该资助](https://reporter.nih.gov/project-details/10715902)。
