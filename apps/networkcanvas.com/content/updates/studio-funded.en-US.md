# NIH funds Network Canvas Studio

A five-year grant from the National Institute on Drug Abuse funds Network Canvas Studio, a cloud platform for collecting social network data remotely and at scale, while keeping the ease of use of the existing tools. [Read the announcement](https://community.networkcanvas.com/t/95).

<!-- more -->

### What Studio will add

Studio is planned to include everything in the desktop and tablet apps, plus:

- interviews in the web browser on any device, for remote self-administration or alongside a researcher
- designing, sharing and editing protocols together as a team
- longitudinal studies that carry data forward from earlier interviews
- an open API for real-time links to analysis software
- role-based access for large project teams
- tools for scheduling surveys and sampling participants
- accessibility improvements, including language localization

### Shaped by the community

The plans grew out of five years of feedback from researchers using Network Canvas, and the team will run surveys and focus groups with the community as the work progresses. [See the grant on NIH RePORTER](https://reporter.nih.gov/project-details/10715902).
