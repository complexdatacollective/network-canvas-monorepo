# Projekt Fresco gefördert: Interviewer im Webbrowser

Eine Ergänzungsförderung der NIH finanziert ein zwölfmonatiges Pilotprojekt, das Interviewer in den Webbrowser bringt, sodass Teilnehmende Interviews aus der Ferne durchführen können, ohne eine App zu installieren. [Ankündigung lesen](https://community.networkcanvas.com/t/17).

<!-- more -->

### Warum der Browser

COVID-19 verlagerte die Interviews zur Partnerbenachrichtigung (Partner Services) im öffentlichen Gesundheitswesen ans Telefon, und die Gesundheitsämter brauchten eine Möglichkeit, Netzwerkdaten zu erheben, ohne sich persönlich zu treffen. Wenn Interviewer im Browser läuft, wird die Selbstausfüllung aus der Ferne möglich, und Interviews können dort stattfinden, wo sich keine App installieren lässt, etwa auf den eigenen Geräten der Teilnehmenden.

### Was das Pilotprojekt verändern wird

Interviewer wurde für Interviews an der Seite einer geschulten Forscherin oder eines geschulten Forschers entwickelt. Damit Teilnehmende auch allein arbeiten können, ergänzt das Projekt klarere Hilfestellungen, eine strengere Navigation sowie Prüfungen in jedem Abschnitt zum Schutz der Datenqualität, außerdem Einführungsschritte, die eine gültige Teilnehmenden-ID verlangen und die von einer Ethikkommission geforderten Einverständniserklärungen anzeigen können.

### Ihre Daten, Ihr Server

Forschende behalten die Kontrolle über ihre Daten. Die App läuft auf Ihrem eigenen Server oder Cloud-Konto, und das Network-Canvas-Team erhebt oder speichert niemals Interviewdaten. Wie der Rest von Network Canvas wird sie offen entwickelt und ist kostenlos nutzbar. [Zur Förderung im NIH RePORTER](https://reporter.nih.gov/project-details/10609285).
