# Network Canvas 6.0: a primeira versão estável

Após quatro anos de desenvolvimento e testes, o Interviewer, o Architect e o Server são lançados como software estável, gratuito e de código aberto para projetar, conduzir e gerenciar entrevistas de redes sociais. [Leia o anúncio](https://www.oii.ox.ac.uk/new-software-tool-to-help-researchers-with-complex-social-network-data-collection-projects-could-be-used-to-fight-covid-19/).

<!-- more -->

### Do beta ao estável

O Network Canvas estava aberto ao público como beta desde junho de 2019. Os relatos de erros, o feedback e os pedidos de recursos dos testadores do beta moldaram as ferramentas, e os pesquisadores com acesso antecipado já as usavam para estudar rastreamento de contatos, sexo e uso de drogas, coesão em comunidades carentes e dinâmicas em sala de aula.

### Três aplicativos, um fluxo de trabalho

O Architect oferece aos pesquisadores uma forma visual de projetar entrevistas de rede. O Interviewer oferece aos participantes uma interface amigável em tela sensível ao toque. O Server reúne em um só lugar as entrevistas de todos os dispositivos, de modo que os dados permanecem nos computadores da própria equipe de pesquisa. O Architect e o Server funcionam no Windows, no macOS e no Linux, e o Interviewer também funciona em iPads e tablets Android.

### Aberto a todos

O conjunto é gratuito e de código aberto, de modo que qualquer pessoa pode ver como ele funciona, adaptá-lo para os seus próprios estudos e contribuir com melhorias. [Leia as notas de versão](https://github.com/complexdatacollective/Interviewer/releases/tag/v6.0.0).
