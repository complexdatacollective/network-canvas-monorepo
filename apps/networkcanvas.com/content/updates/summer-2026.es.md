Hemos reconstruido Architect e Interviewer como sitios web que puede abrir en cualquier dispositivo o instalar como aplicaciones, e Interviewer vuelve a funcionar en iPad y tabletas Android. Junto con Fresco 4.0.0, comparten una base común y un nuevo formato de protocolo, Schema 8, que incorpora diversas novedades:

- **Seis nuevas interfaces de entrevista**, entre ellas mapas geoespaciales, pedigrís familiares y un compositor de redes de forma libre.
- **Mejoras en los protocolos**, entre ellas una validación más completa, una lógica de omisión mejorada y formas de nodo configurables.
- **Fresco 4.0.0**, con cuentas para todo el equipo, una API de datos segura y alojamiento propio completo.
- **Actualizaciones automáticas y mayor seguridad**, incluido el almacenamiento cifrado de datos en Interviewer.
