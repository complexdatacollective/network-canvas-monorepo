# 论文：Network Canvas 发表于 International Journal of Epidemiology

社会影响和接触网络对于理解健康行为和疾病传播至关重要，但大多数调查软件并非为捕捉这些信息而设计。这篇论文向流行病学家介绍了 Network Canvas，将其作为设计和开展网络访谈的端到端工作流程。

论文介绍了 Architect、Interviewer 和 Server 这三款应用（可在 Windows、macOS 和 Linux 上运行，Interviewer 还支持 Android 和 iOS），以及它们的点选式设计如何降低收集网络数据所需的技术知识。Network Canvas 是开源软件，依据 GNU 通用公共许可证第 3 版免费提供。[阅读论文](https://doi.org/10.1093/ije/dyad036)。
