# 論文：Network Canvas 發表於《International Journal of Epidemiology》

社會影響與接觸網絡是理解健康行為與疾病傳播方式的核心，然而大多數問卷軟體並非為了蒐集這類資料而設計。這篇論文向流行病學研究者介紹 Network Canvas，說明它是一套用於設計並進行網絡訪談的完整工作流程。

論文介紹了 Architect、Interviewer 與 Server 這三個應用程式（可在 Windows、macOS 與 Linux 上執行，Interviewer 另可在 Android 與 iOS 上執行），以及它們以點選操作為主的設計如何降低蒐集網絡資料所需的技術門檻。Network Canvas 是開放原始碼軟體，依 GNU General Public License 3 授權免費提供。[閱讀論文](https://doi.org/10.1093/ije/dyad036)。
