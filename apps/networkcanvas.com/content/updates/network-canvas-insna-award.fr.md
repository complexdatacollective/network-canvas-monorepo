# Network Canvas reçoit un prix de l’INSNA

L’International Network for Social Network Analysis a décerné son prix logiciel William D. Richards, Jr. 2025 à l’équipe de Network Canvas pour le développement d’un outil libre et gratuit de collecte de données sur les réseaux sociaux interpersonnels. [En savoir plus sur le prix](https://insna.org/richards-awards).
