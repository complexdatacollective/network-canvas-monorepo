# Network Canvas 6.0: die erste stabile Version

Nach vier Jahren Entwicklung und Tests erscheinen Interviewer, Architect und Server als stabile, kostenlose Open-Source-Software zum Entwerfen, Durchführen und Verwalten sozialer Netzwerkinterviews. [Ankündigung lesen](https://www.oii.ox.ac.uk/new-software-tool-to-help-researchers-with-complex-social-network-data-collection-projects-could-be-used-to-fight-covid-19/).

<!-- more -->

### Von der Beta zur stabilen Version

Network Canvas war seit Juni 2019 als Beta öffentlich zugänglich. Fehlerberichte, Rückmeldungen und Funktionswünsche der Beta-Testenden prägten die Werkzeuge, und Forschende mit frühem Zugang nutzten sie bereits, um Kontaktnachverfolgung, Sexualverhalten und Drogenkonsum, Zusammenhalt in benachteiligten Gemeinschaften und Dynamiken im Klassenzimmer zu untersuchen.

### Drei Apps, ein Arbeitsablauf

Architect bietet Forschenden eine visuelle Möglichkeit, Netzwerkinterviews zu entwerfen. Interviewer bietet Teilnehmenden eine freundliche Touchscreen-Oberfläche. Server sammelt die Interviews von allen Geräten an einem Ort, sodass die Daten auf den eigenen Computern des Forschungsteams bleiben. Architect und Server laufen unter Windows, macOS und Linux, und Interviewer läuft zusätzlich auf iPads und Android-Tablets.

### Offen für alle

Die Suite ist kostenlos und Open Source, sodass jede und jeder nachvollziehen kann, wie sie funktioniert, sie für eigene Studien anpassen und Verbesserungen beisteuern kann. [Versionshinweise lesen](https://github.com/complexdatacollective/Interviewer/releases/tag/v6.0.0).
