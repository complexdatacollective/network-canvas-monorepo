# Joshua Melville 獲得為期兩年的 NIH 經費，用於維護 Network Canvas

美國國家藥物濫用研究所（NIDA）授予 Network Canvas 的主要開發人員 Joshua Melville 一項專為研究軟體工程師設立的 NIH 研究專員獎助（Research Specialist award，R50）。這項補助資助兩年的工作（2026 年 7 月至 2028 年 6 月），讓 Network Canvas 作為開放科學軟體，持續保持可維護、安全且永續。

這項獎助建立在近十年來 NIH 對 Network Canvas 的資助之上，目前至少有 55 項由 NIH 資助的研究使用 Network Canvas，主題涵蓋從鴉片類物質使用障礙，到對微生物群落的社會影響。在這兩年間，Joshua 將把程式碼遷移到 TypeScript 並解決關鍵的技術債、強化 Architect、讓網頁版訪談應用程式支援離線訪談，並透過新的訓練資源，擴大圍繞這套軟體的社群。[在 NIH RePORTER 上查看計畫詳情](https://reporter.nih.gov/project-details/11339209)。
