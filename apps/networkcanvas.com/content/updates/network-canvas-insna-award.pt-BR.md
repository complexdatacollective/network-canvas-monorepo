# Network Canvas ganha prêmio da INSNA

A International Network for Social Network Analysis concedeu seu prêmio de software William D. Richards, Jr. de 2025 à equipe do Network Canvas por desenvolver uma ferramenta gratuita e de código aberto para a coleta de dados de redes sociais. [Saiba mais sobre o prêmio](https://insna.org/richards-awards).
