# Schema 6, e os aplicativos para desktop entram em modo de manutenção

O Architect 6.3 e o Interviewer 6.2 trazem layout automático de sociogramas, uma interface de lista unificada e busca de etapas no Architect. Com esta versão, os aplicativos para desktop passam ao modo de manutenção, enquanto a equipe se dedica a novos projetos. [Leia a atualização do projeto](https://community.networkcanvas.com/t/16).
