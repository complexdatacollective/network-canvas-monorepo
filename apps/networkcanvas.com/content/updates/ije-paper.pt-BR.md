# Artigo: o Network Canvas no International Journal of Epidemiology

A influência social e as redes de contato são fundamentais para entender os comportamentos de saúde e a forma como as doenças se espalham, mas a maioria dos softwares de questionário não foi feita para captá-las. Este artigo apresenta o Network Canvas aos epidemiologistas como um fluxo de trabalho completo para projetar e conduzir entrevistas de rede.

Ele descreve os três aplicativos, Architect, Interviewer e Server, que funcionam no Windows, no macOS e no Linux, com o Interviewer também disponível para Android e iOS, e como o seu design de apontar e clicar reduz o conhecimento técnico necessário para coletar dados de rede. O Network Canvas é de código aberto e gratuito, sob a Licença Pública Geral GNU 3. [Leia o artigo](https://doi.org/10.1093/ije/dyad036).
