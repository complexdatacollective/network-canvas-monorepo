# 新一代 Network Canvas 應用程式

Architect 與 Interviewer 已重新打造為網站，您可以在任何裝置上開啟，也可以將其安裝為應用程式；Interviewer 也重新支援 iPad 與 Android 平板電腦。它們與 Fresco 4.0.0 共用同一基礎和一種新的協定格式 Schema 8，帶來一系列新功能：

- **六種新的訪談介面**，包括地理空間地圖、家族譜系圖和自由形式的網路編輯器。
- **協定改進**，包括更完整的驗證、強化的跳題邏輯和可設定的節點形狀。
- **Fresco 4.0.0**，提供團隊帳戶、安全的資料 API 和完整的自行託管。
- **自動更新與更強的安全性**，包括 Interviewer 中的加密資料儲存。
