# Fresco 1.0

La première version stable de Fresco. Hébergez-le sur votre propre serveur, importez les protocoles que vous avez conçus dans Architect, et laissez les participants réaliser des entretiens Network Canvas dans leur navigateur web. [Lire les notes de version](https://github.com/complexdatacollective/Fresco/releases/tag/v1.0.0).

<!-- more -->

### Prêt pour la recherche

Fresco a été lancé en version bêta publique en mars 2024. Après des tests menés par la communauté, la version 1.0 retire la mention bêta : Fresco est prêt pour la collecte de données de recherche.

### Des entretiens dans le navigateur

Fresco offre aux participants le même aspect, la même expérience et les mêmes interfaces qu’Interviewer, et exporte les données dans les mêmes formats. Les participants peuvent rejoindre une étude grâce à un lien, ce qui permet de réaliser les entretiens à distance, et Fresco comprend une gestion de base des participants et du recrutement. Il fonctionne avec n’importe quel protocole créé dans Architect.

### Essayez-le d’abord

La documentation comprend un bac à sable pour explorer Fresco sans le déployer, ainsi que des instructions pas à pas pour déployer votre propre copie. [Lire la documentation de Fresco](https://documentation.networkcanvas.com/en/collect-data/fresco/about).
