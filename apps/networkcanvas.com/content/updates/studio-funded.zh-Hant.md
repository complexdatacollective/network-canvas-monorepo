# NIH 資助 Network Canvas Studio

美國國家藥物濫用研究所（NIDA）的一項五年期補助，將資助 Network Canvas Studio，這是一個可遠端、大規模蒐集社會網絡資料的雲端平台，同時保有現有工具的易用性。[閱讀公告](https://community.networkcanvas.com/t/95)。

<!-- more -->

### Studio 將新增哪些功能

Studio 規劃包含桌面與平板應用程式的所有功能，另外還有：

- 可在任何裝置的網頁瀏覽器中進行訪談，適用於遠端自行填答，或在研究人員陪同下進行
- 團隊可共同設計、分享與編輯協定
- 縱貫性研究，可延續先前訪談的資料
- 開放的 API，可即時連結分析軟體
- 針對大型專案團隊的角色權限管理
- 用於排程調查與抽樣參與者的工具
- 無障礙功能的改進，包括多語言支援

### 由社群共同塑造

這些規劃源自五年來使用 Network Canvas 的研究人員所提供的意見回饋，團隊也會在工作進行期間，與社群一同進行問卷調查與焦點團體。[在 NIH RePORTER 上查看此補助](https://reporter.nih.gov/project-details/10715902)。
