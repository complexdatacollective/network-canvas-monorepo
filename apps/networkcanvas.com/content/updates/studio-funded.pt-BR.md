# NIH financia o Network Canvas Studio

Um financiamento de cinco anos do National Institute on Drug Abuse apoia o Network Canvas Studio, uma plataforma em nuvem para coletar dados de redes sociais remotamente e em grande escala, mantendo a facilidade de uso das ferramentas existentes. [Leia o anúncio](https://community.networkcanvas.com/t/95).

<!-- more -->

### O que o Studio vai acrescentar

O Studio deve incluir tudo o que existe nos aplicativos para desktop e tablet, além de:

- entrevistas no navegador, em qualquer dispositivo, para autoaplicação remota ou ao lado de um pesquisador
- criação, compartilhamento e edição de protocolos em equipe
- estudos longitudinais que levam adiante os dados de entrevistas anteriores
- uma API aberta para conexões em tempo real com programas de análise
- acesso baseado em funções para grandes equipes de projeto
- ferramentas para agendar pesquisas e amostrar participantes
- melhorias de acessibilidade, incluindo a localização de idiomas

### Moldado pela comunidade

Os planos nasceram de cinco anos de feedback de pesquisadores que usam o Network Canvas, e a equipe fará pesquisas e grupos focais com a comunidade à medida que o trabalho avançar. [Veja o financiamento no NIH RePORTER](https://reporter.nih.gov/project-details/10715902).
