# El NIH financia Network Canvas Studio

Una subvención de cinco años del National Institute on Drug Abuse financia Network Canvas Studio, una plataforma en la nube para recopilar datos de redes sociales de forma remota y a gran escala, sin perder la facilidad de uso de las herramientas existentes. [Lea el anuncio](https://community.networkcanvas.com/t/95).

<!-- more -->

### Qué añadirá Studio

Está previsto que Studio incluya todo lo que ofrecen las aplicaciones de escritorio y tableta, y además:

- entrevistas en el navegador web en cualquier dispositivo, para la autoadministración remota o junto a un investigador
- diseño, uso compartido y edición de protocolos en equipo
- estudios longitudinales que reutilizan los datos de entrevistas anteriores
- una API abierta para conexiones en tiempo real con software de análisis
- acceso basado en roles para equipos de proyecto numerosos
- herramientas para programar encuestas y muestrear participantes
- mejoras de accesibilidad, incluida la localización de idiomas

### Moldeado por la comunidad

Los planes surgieron de cinco años de comentarios de investigadores que usan Network Canvas, y el equipo realizará encuestas y grupos de discusión con la comunidad a medida que avance el trabajo. [Consulte la subvención en NIH RePORTER](https://reporter.nih.gov/project-details/10715902).
