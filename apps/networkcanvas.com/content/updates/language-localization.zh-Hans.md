# Network Canvas 的多语言支持

Architect、Interviewer 和 Fresco 现已支持多种语言！多语言支持一直是呼声最高的功能之一，现在您可以使用英语、英式英语或西班牙语来使用这些应用，参与者在访谈中看到的界面也包括在内。只需在每个应用中点击地球图标，或在访谈期间从设置菜单中选择语言即可。更多语言即将推出。

<!-- more -->

### 哪些内容已翻译？

应用界面中的所有内容：按钮、引导、对话框和消息，包括参与者在访谈中看到的内容。您的协议内容（问题、提示、标签和答案选项）会完全按照您编写的方式显示，您收集的数据也不受影响。协议内容的翻译将在未来的版本中推出。

默认情况下，每个应用都会跟随您浏览器的语言。Architect 和 Interviewer 会在每台设备上记住您的选择，Fresco 则会将其保存到您的账户中。

### 更多语言即将推出

我们正在努力添加更多语言。这些首批翻译主要由机器完成，因此部分措辞可能读起来不太自然。如果您发现问题，或希望帮助为 Network Canvas 引入新的语言，我们非常期待您的来信。请发送电子邮件至 [info@networkcanvas.com](mailto:info@networkcanvas.com)，或在[用户社区](https://community.networkcanvas.com/)发帖。对于协助新语言翻译的人士，我们或许可以提供有限的报酬。

感谢您的所有反馈，它们帮助我们决定接下来要构建什么！
