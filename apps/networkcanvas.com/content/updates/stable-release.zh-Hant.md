# Network Canvas 6.0：第一個穩定版本

歷經四年的開發與測試，Interviewer、Architect 與 Server 作為穩定、免費且開放原始碼的軟體正式釋出，可用於設計、進行與管理社會網絡訪談。[閱讀公告](https://www.oii.ox.ac.uk/new-software-tool-to-help-researchers-with-complex-social-network-data-collection-projects-could-be-used-to-fight-covid-19/)。

<!-- more -->

### 從測試版到穩定版

自 2019 年 6 月起，Network Canvas 便以測試版的形式向大眾開放。測試人員的錯誤回報、意見回饋與功能建議塑造了這些工具，而取得搶先使用資格的研究人員，已用它們來研究接觸者追蹤、性與藥物使用、弱勢社區的凝聚力，以及課堂互動。

### 三個應用程式，一套工作流程

Architect 為研究人員提供視覺化的方式來設計網絡訪談。Interviewer 為參與者提供親切易用的觸控介面。Server 則將來自每部裝置的訪談集中蒐集在同一處，因此資料會保存在研究團隊自己的電腦上。Architect 與 Server 可在 Windows、macOS 與 Linux 上執行，Interviewer 另可在 iPad 與 Android 平板電腦上執行。

### 向所有人開放

這套工具免費且開放原始碼，因此任何人都能了解其運作方式、依自己的研究調整，並將改進回饋給專案。[閱讀版本資訊](https://github.com/complexdatacollective/Interviewer/releases/tag/v6.0.0)。
