# 論文：Network Canvas 設計中的關鍵決策

自我報告式的網絡研究往往相當複雜且負擔沉重，無論是在訪談過程中，還是在事後管理資料時皆然。在這篇發表於《Social Networks》的論文中，團隊說明了 Network Canvas 套件背後的設計決策：以 Architect 設計訪談協定、以 Interviewer 在觸控螢幕上進行訪談，並以 Server 管理部署與匯出資料。

這些工具共同為技術背景有限的研究人員提供了完整的工作流程，從自行建立網絡訪談，到將資料蒐集到安全的中央位置。論文闡述了這些關鍵設計選擇背後的理論、哲學與實務理由、引導這些選擇的經驗，以及它們的優勢與限制。[閱讀論文](https://doi.org/10.1016/j.socnet.2021.02.003)。
