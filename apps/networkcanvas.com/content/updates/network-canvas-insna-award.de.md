# Network Canvas erhält INSNA-Auszeichnung

Das International Network for Social Network Analysis hat dem Network-Canvas-Team den William D. Richards, Jr. Software Award 2025 verliehen – für die Entwicklung eines kostenlosen Open-Source-Werkzeugs zur Erhebung sozialer Netzwerkdaten. [Mehr über die Auszeichnung](https://insna.org/richards-awards).
