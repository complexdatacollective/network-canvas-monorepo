# Network Canvas 6.0: de eerste stabiele release

Na vier jaar ontwikkeling en testen worden Interviewer, Architect en Server uitgebracht als stabiele, gratis opensourcesoftware voor het ontwerpen, afnemen en beheren van sociale-netwerkinterviews. [Lees de aankondiging](https://www.oii.ox.ac.uk/new-software-tool-to-help-researchers-with-complex-social-network-data-collection-projects-could-be-used-to-fight-covid-19/).

<!-- more -->

### Van bèta naar stabiel

Network Canvas was sinds juni 2019 als bèta openbaar beschikbaar. Foutmeldingen, feedback en functieverzoeken van bètatesters hebben de tools gevormd, en onderzoekers met vroege toegang gebruikten ze al om contactonderzoek, seks en druggebruik, cohesie in achtergestelde gemeenschappen en dynamiek in klaslokalen te bestuderen.

### Drie apps, één werkwijze

Architect geeft onderzoekers een visuele manier om netwerkinterviews te ontwerpen. Interviewer geeft deelnemers een vriendelijke touchscreeninterface. Server verzamelt interviews van alle apparaten op één plek, zodat de gegevens op de eigen computers van het onderzoeksteam blijven. Architect en Server draaien op Windows, macOS en Linux, en Interviewer draait ook op iPads en Android-tablets.

### Open voor iedereen

De suite is gratis en opensource, zodat iedereen kan zien hoe het werkt, het kan aanpassen voor eigen onderzoek en verbeteringen kan terugleveren. [Lees de release notes](https://github.com/complexdatacollective/Interviewer/releases/tag/v6.0.0).
