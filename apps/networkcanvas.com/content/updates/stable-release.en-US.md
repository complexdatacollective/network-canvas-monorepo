# Network Canvas 6.0: the first stable release

After four years of development and testing, Interviewer, Architect and Server are released as stable, free and open-source software for designing, conducting and managing social network interviews. [Read the announcement](https://www.oii.ox.ac.uk/new-software-tool-to-help-researchers-with-complex-social-network-data-collection-projects-could-be-used-to-fight-covid-19/).

<!-- more -->

### From beta to stable

Network Canvas had been open to the public as a beta since June 2019. Beta testers' bug reports, feedback and feature requests shaped the tools, and early-access researchers were already using them to study contact tracing, sex and drug use, cohesion in deprived communities, and classroom dynamics.

### Three apps, one workflow

Architect gives researchers a visual way to design network interviews. Interviewer gives participants a friendly touchscreen interface. Server gathers interviews from every device in one place, so the data stays on the research team's own computers. Architect and Server run on Windows, macOS and Linux, and Interviewer also runs on iPads and Android tablets.

### Open to everyone

The suite is free and open source, so anyone can see how it works, adapt it for their own studies, and contribute improvements back. [Read the release notes](https://github.com/complexdatacollective/Interviewer/releases/tag/v6.0.0).
