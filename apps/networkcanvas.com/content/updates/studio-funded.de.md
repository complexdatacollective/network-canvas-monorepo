# NIH fördert Network Canvas Studio

Eine fünfjährige Förderung des National Institute on Drug Abuse finanziert Network Canvas Studio, eine Cloud-Plattform zur Erhebung sozialer Netzwerkdaten aus der Ferne und in großem Umfang, die die einfache Bedienung der bestehenden Werkzeuge beibehält. [Ankündigung lesen](https://community.networkcanvas.com/t/95).

<!-- more -->

### Was Studio ergänzen wird

Studio soll alles enthalten, was die Desktop- und Tablet-Apps bieten, und zusätzlich:

- Interviews im Webbrowser auf jedem Gerät, zur Selbstausfüllung aus der Ferne oder an der Seite einer Forscherin oder eines Forschers
- gemeinsames Entwerfen, Teilen und Bearbeiten von Protokollen im Team
- Längsschnittstudien, die Daten aus früheren Interviews fortführen
- eine offene API für Echtzeitverbindungen zu Analysesoftware
- rollenbasierter Zugriff für große Projektteams
- Werkzeuge zur Terminplanung von Umfragen und zur Stichprobenziehung von Teilnehmenden
- Verbesserungen bei der Barrierefreiheit, einschließlich Sprachlokalisierung

### Von der Community mitgestaltet

Die Pläne entstanden aus fünf Jahren Rückmeldungen von Forschenden, die Network Canvas nutzen, und das Team wird im Verlauf der Arbeit Umfragen und Fokusgruppen mit der Community durchführen. [Zur Förderung im NIH RePORTER](https://reporter.nih.gov/project-details/10715902).
