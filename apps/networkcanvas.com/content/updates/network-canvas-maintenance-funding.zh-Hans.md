# Joshua Melville 获得两年 NIH 资助，用于维护 Network Canvas

美国国家药物滥用研究所（NIDA）向 Network Canvas 首席开发人员 Joshua Melville 授予了面向研究软件工程师的 NIH 研究专员奖（R50）。该奖项资助 2026 年 7 月至 2028 年 6 月为期两年的工作，使 Network Canvas 作为开放科学软件保持可维护、安全和可持续。

该奖项建立在近十年来 NIH 对 Network Canvas 的资助基础之上；目前至少有 55 项 NIH 资助的研究在使用 Network Canvas，涵盖从阿片类药物使用障碍到微生物群落的社会影响等主题。在这两年中，Joshua 将把代码迁移到 TypeScript 并解决关键的技术债务，增强 Architect，通过基于网页的访谈应用支持离线访谈，并借助新的培训资源壮大围绕该软件的社区。[在 NIH RePORTER 上查看项目详情](https://reporter.nih.gov/project-details/11339209)。
