# La personne qui dirige le développement de Network Canvas obtient deux ans de financement pour assurer la maintenance du logiciel

Le National Institute on Drug Abuse finance deux années de travail pour maintenir et améliorer Network Canvas en tant que logiciel de science ouverte. [Consulter les détails du projet sur NIH RePORTER](https://reporter.nih.gov/search/vB-u312oGkW58r46HT8FmA/project-details/11339209).
