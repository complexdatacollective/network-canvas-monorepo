# Fresco 1.0

Die erste stabile Version von Fresco. Betreiben Sie es auf Ihrem eigenen Server, laden Sie Protokolle hoch, die Sie in Architect entworfen haben, und lassen Sie Teilnehmende Network-Canvas-Interviews in ihrem Webbrowser durchführen. [Versionshinweise lesen](https://github.com/complexdatacollective/Fresco/releases/tag/v1.0.0).

<!-- more -->

### Bereit für die Forschung

Fresco startete im März 2024 als öffentliche Beta. Nach Tests durch die Community entfällt mit Version 1.0 die Beta-Kennzeichnung: Fresco ist bereit für die Erhebung von Forschungsdaten.

### Interviews im Browser

Fresco bietet Teilnehmenden dasselbe Aussehen, dieselbe Bedienung und dieselben Oberflächen wie Interviewer und exportiert Daten in denselben Formaten. Teilnehmende können über einen Link an einer Studie teilnehmen, sodass Interviews aus der Ferne stattfinden können, und Fresco enthält eine einfache Teilnehmendenverwaltung und Rekrutierung. Es funktioniert mit jedem in Architect erstellten Protokoll.

### Erst ausprobieren

Die Dokumentation enthält eine Sandbox, in der Sie Fresco erkunden können, ohne es bereitzustellen, sowie eine Schritt-für-Schritt-Anleitung zur Bereitstellung Ihrer eigenen Installation. [Fresco-Dokumentation lesen](https://documentation.networkcanvas.com/en/collect-data/fresco/about).
