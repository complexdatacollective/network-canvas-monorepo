# Network Canvas 的多語言支援

Architect、Interviewer 與 Fresco 現已支援多種語言！多語言支援一直是呼聲最高的功能之一，現在您可以使用英文、英式英文或西班牙文來使用這些應用程式，參與者在訪談中看到的介面也包括在內。只要在每個應用程式中點選地球圖示，或在訪談期間從設定選單中選擇語言即可。更多語言即將推出。

<!-- more -->

### 哪些內容已翻譯？

應用程式介面中的所有內容：按鈕、引導、對話方塊和訊息，包括參與者在訪談中看到的內容。您的協定內容（問題、提示、標籤和答案選項）會完全依照您撰寫的方式顯示，您蒐集的資料也不受影響。協定內容的翻譯將在未來的版本中推出。

預設情況下，每個應用程式都會跟隨您瀏覽器的語言。Architect 與 Interviewer 會在每部裝置上記住您的選擇，Fresco 則會將其儲存到您的帳戶中。

### 更多語言即將推出

我們正在努力新增更多語言。這些首批翻譯主要由機器完成，因此部分措辭讀起來可能不太自然。如果您發現問題，或希望協助為 Network Canvas 引進新的語言，我們非常期待您的來信。請寄送電子郵件至 [info@networkcanvas.com](mailto:info@networkcanvas.com)，或在[使用者社群](https://community.networkcanvas.com/)發文。對於協助新語言翻譯的人士，我們或許能提供有限的報酬。

感謝您的所有意見回饋，它們幫助我們決定接下來要打造什麼！
