# Network Canvas 6.0：首个稳定版本

经过四年的开发和测试，Interviewer、Architect 和 Server 作为稳定、免费、开源的软件正式发布，用于设计、开展和管理社会网络访谈。[阅读公告](https://www.oii.ox.ac.uk/new-software-tool-to-help-researchers-with-complex-social-network-data-collection-projects-could-be-used-to-fight-covid-19/)。

<!-- more -->

### 从测试版到稳定版

自 2019 年 6 月起，Network Canvas 以测试版的形式向公众开放。测试者提交的错误报告、反馈和功能请求塑造了这些工具，而抢先体验的研究人员已经在用它们研究接触者追踪、性行为与药物使用、贫困社区的凝聚力以及课堂动态。

### 三款应用，一套工作流程

Architect 为研究人员提供了设计网络访谈的可视化方式。Interviewer 为参与者提供友好的触屏界面。Server 将来自各台设备的访谈汇集到一处，因此数据始终保存在研究团队自己的计算机上。Architect 和 Server 可在 Windows、macOS 和 Linux 上运行，Interviewer 还可在 iPad 和 Android 平板电脑上运行。

### 向所有人开放

这套工具免费且开源，任何人都可以了解其工作原理，将其改编后用于自己的研究，并贡献改进。[阅读发布说明](https://github.com/complexdatacollective/Interviewer/releases/tag/v6.0.0)。
