# 新一代 Network Canvas 应用

Architect 和 Interviewer 已重新构建为网站，您可以在任何设备上打开，也可以将其安装为应用；Interviewer 也重新支持 iPad 和 Android 平板电脑。它们与 Fresco 4.0.0 共享同一基础和一种新的协议格式 Schema 8，带来了一系列新功能：

- **六种新的访谈界面**，包括地理空间地图、家族谱系图和自由形式的网络编辑器。
- **协议改进**，包括更丰富的验证、增强的跳转逻辑和可配置的节点形状。
- **Fresco 4.0.0**，提供团队账户、安全的数据 API 和完整的自托管。
- **自动更新与更强的安全性**，包括 Interviewer 中的加密数据存储。
