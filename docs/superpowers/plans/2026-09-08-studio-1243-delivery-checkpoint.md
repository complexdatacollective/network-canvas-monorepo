## Durable workflow

Checkpoints preserve work; they do not establish release readiness. Raw logs and exact-source archives stay in the persistent evidence directory. Sanitized results belong here and in PRs. No secrets or live credentials belong in Git or logs.

Each worktree has one committer. The lead owns integration and this coordination tree; agents own separate implementation trees and PostgreSQL fixture ports. Before reassignment, agents checkpoint coherent changes. No worktree is removed until its commits are reachable from a remote branch and uncommitted work is preserved. Container image qualification uses an archive of an exact commit, so concurrent work cannot change the build context. The lead checks actual agent status and keeps all three slots assigned to independent useful work using Sol medium or Luna high.
