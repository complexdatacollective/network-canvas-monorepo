In a Family Pedigree stage, the name attribute's "Required answer" rule can no
longer be switched on or off. The stage always gives every family member a
value there, either the name the participant types or a label made from their
relationship to the participant, so the rule would always be met. A note
beneath the rule says so. The rule still
applies where the same attribute is asked on other stages.
