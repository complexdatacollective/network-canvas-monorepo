The documentation is now available in Spanish. Readers whose browser asks for
Spanish, or who chose Spanish on any Network Canvas website, get the Spanish
pages, and a language switcher in the footer changes language. Search shows
results in the page's language. The text inside the documentation's own
components (interface summaries, the compatibility and workflow tables, code
examples, the "not found" page) is translated too, and an interface summary's
requirements keep their icons in Spanish.
