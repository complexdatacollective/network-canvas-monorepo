The Protocol Schema Information page explains the ids in a schema 9 protocol. Every stage, prompt, panel, form field, filter rule and other item a stage keeps in a list has an id that is a UUID used only once in the protocol. The page says that an upgrade from schema 8 gives every one of them a new id, and that Architect assigns ids for you. It also explains that the ids of node types, edge types and variables are UUIDs, that an upgrade gives each of them a new id without changing its name, and that roster files still match variables by name. Updated in English, Spanish and French.
