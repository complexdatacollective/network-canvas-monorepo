The Protocol Schema Information page explains the ids in a schema 9 protocol. Every stage, prompt, panel, form field, filter rule and other item a stage keeps in a list has an id that is a UUID used only once in the protocol. The page says which ids an upgrade from schema 8 keeps and which it replaces, and that Architect assigns ids for you. Updated in English, Spanish and French.
