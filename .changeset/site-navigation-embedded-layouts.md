`SiteNavigation` takes a `layout`. `embedded` renders the logo and links alone, for a host's own header bar, and measures how many links fit in the room it is given (`onFitChange` reports it); `menu` lists the links for a host's own menu. `hostMenu` turns the active entry of the embedded header into the button that opens the host's menu. The Software menu now wraps its cards onto more rows in a window too narrow for three across, instead of running off the screen.
