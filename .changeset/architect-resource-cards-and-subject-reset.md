The resource library shows each resource as a card, with its picture above
its name and badges for its type and whether it is saved. The import button
in the library is styled like the other buttons in Architect. The browser's
own "no file chosen" control no longer appears.

Choosing the first node type for a Network Composer, Sociogram, Narrative or
One to Many Dyad Census stage no longer asks you to confirm
losing the rest of the stage when you have not changed anything yet.
Architect still asks when you have changed a setting away from its default,
because changing the node type would reset it.
