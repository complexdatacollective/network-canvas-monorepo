A scrolling area or table that overflows now becomes reachable by keyboard as soon as it appears, instead of a moment later, so keyboard and screen reader users are never left with a region they cannot scroll. The language switcher's list is now announced by the name of its heading, and is a single keyboard stop when it has no search box. The Everything Bar's results list is now the box that scrolls, so assistive technology sees one results list rather than a list inside an unnamed scrolling region.
