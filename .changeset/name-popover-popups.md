Popovers can now be given a name that screen readers announce when they open. A new `PopoverTitle` marks a heading inside a popover as its name, and the toolbar popover reuses the label of its icon button by default. The icon picker's list of icons is now named after the field it belongs to, so it is announced as "Icon" rather than as an unnamed dialog.
