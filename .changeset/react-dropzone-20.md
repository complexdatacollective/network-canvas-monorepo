File drop areas are updated to a newer version of the upload component. A file can now be pasted onto a focused drop area, the hidden file picker carries an accessible label, and dropping a file onto a drop area that is busy or disabled no longer opens it in a new browser tab. Dropping several files where only one is expected still opens nothing.
