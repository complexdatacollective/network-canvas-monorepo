The Updates page now lists every release alongside feature launches, in three
categories: launches, feature updates and bug fixes. Each entry carries a
coloured category label and a matching dot on the timeline, and the search and
filters sit together in one panel, with a count of the updates in view and a
"Clear all" link. The same entries are published as JSON at
`/api/updates.json`, which the apps read their release notes from.
