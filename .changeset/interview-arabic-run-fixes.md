In an interview in any language other than English:

- Close buttons on dialogs no longer show an English "Close" tooltip.
- The quick-add button no longer shows an English tooltip, and a name being typed into it is shown in the interview's language, so an Arabic name gets the Arabic typeface.
- Names and details on roster cards read in their own direction, so a Latin name keeps its punctuation in place in an Arabic interview.

Both buttons that add a person are named for screen readers from the icon of the person's type, such as "Add a place", or "Add" for an icon that does not say what it adds. The form's button was "Add a person" whatever the icon, and the quick-add button had no name with such an icon.
