The Narrative Pedigree interface page describes the interface as it reads the
redesigned Family Pedigree: it draws the participant and everyone connected to
them through the pedigree's relationships, labels people as the pedigree did
(asking for the passphrase when names are encrypted), takes each symbol's
shape from the person type, and can be used from the keyboard. A disease maps
a node attribute that one of the source pedigree's nomination prompts records.
The page explains that sex-linked inheritance follows sex assigned at birth,
that an intersex person is never assumed to have one X chromosome or two, and
that mitochondrial donation can be traced only in imported data. The Family
Pedigree page and the schema history mention the Narrative Pedigree again.
