The Codebook page now opens the same node type, edge type and attribute
editors as the stage editors. The type editor is titled "Create new node type"
or "Edit this node type" (and the same for edge types) and saves with "Save
entity". The attribute editor is titled "Create attribute". Problems with a
type or an attribute are reported when you save, and the first field that
needs attention receives focus. Closing any of these editors with unsaved
changes asks "Discard your changes?" first, on the Codebook page and in the
stage editors. If the image for a custom shape is no longer available when you
save, the message appears under Custom shapes and names the shape. Node types,
edge types and attributes can also be created from the codebook shown on the
Summary page.
