The Family Pedigree interface page now describes the interface as it works today: how participants add and describe relatives, the person and relationship attributes the stage records, the wording, completeness and nomination prompt settings, and where a person's symbol comes from. The Implementing CEGRM tutorial no longer describes an attribute that nothing writes, and matches the bundled template's 14 stages, which ask about the condition and testing through nomination prompts and end with a Narrative Pedigree before the closing screen. It also explains that the template marks non-kin people with a `non_kin` attribute, instead of using gender identity to tell family from non-kin.
