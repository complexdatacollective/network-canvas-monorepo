The Fresco self-hosting guides now describe Garage as the storage bundled with the Docker deployment, in place of MinIO. The Advanced Deployment guide explains how to generate the four Garage secrets for your `.env`, which values to enter in the setup wizard's storage step, and the Docker versions the bundled configuration needs. The FAQ for IT Departments now explains how to encrypt the bundled storage at rest.
