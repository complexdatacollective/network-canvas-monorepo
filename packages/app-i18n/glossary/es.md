# Spanish (es) terminology glossary

How Network Canvas names its concepts and interfaces in Spanish. It applies to
every surface with Spanish text: the apps' and packages' catalogs,
networkcanvas.com, the documentation and protocol text. (networkcanvas.com is
being moved from usted to tú; until that lands its catalog still uses usted.) Translate with it, and
review translations against it. The terms come from the Spanish the apps
already ship, so a page names a screen, button or setting the way the reader
sees it in the app.

When a translation needs a term that is not here, look for it in the app
catalogs first (`apps/*/src/locales/es.json`, `packages/*/src/locales/es.json`),
then add it here in the same change. A new or changed entry is verified like
any translation (see the `verifying-translations` skill), and catalog strings
that use an old term change with it.

## Register and style

- Address the reader as **tú**, as the apps do. Prefer impersonal phrasing
  ("se puede…", "para añadir…") where it reads naturally.
- Use Spain's conventions: "vídeo", "añadir", "ordenador", "subir", and the
  present perfect for recent events ("No se han encontrado opciones").
- Interface names are proper names: capitalised, in «guillemets», after a
  common noun: "la interfaz «Narrativa»", "una etapa «Información»". Never turn
  one into an adjective ("etapa narrativa" could mean «Narrativa» or
  «Genealogía narrativa»). The exception is the two picker labels that begin
  with "Interfaz" (Anonymisation Interface, Geospatial Interface): write them as
  plain descriptions, "la interfaz de anonimización", "una etapa geoespacial".
- On a term's first use on a documentation page, gloss the specialist terms
  marked _gloss_ below.

## Never translated

Network Canvas, Architect, Interviewer, Fresco, Studio, Network Canvas
Interviewer, file formats (`.netcanvas`, CSV, GraphML), and anything inside
code blocks or inline code. "Interviewer" the app is never translated; the
person who conducts an interview is "la persona entrevistadora".

## Inclusive language

Use wording that is neutral by construction: "cada participante", "quienes
participan", "la persona participante", "quienes investigan", "quien
investiga", "el equipo de investigación", "la persona entrevistadora". Do not
use doubled or new forms ("los/las", "l@s", "lxs", "les"): they lengthen the
text, the RAE advises against them, and screen readers read them badly. Where
a neutral construction would be forced, the plural "participantes" without an
article usually works.
